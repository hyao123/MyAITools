# MyAITools

**GitHub 高分 AI 工具精选** — 只收能解决真实痛点的。

## 入选标准

- GitHub Stars > 5K（或商业产品有显著影响力）
- 必须能切实解决开发/工作中的某个痛点
- 活跃维护，非 archived 项目
- 拒绝玩具级 demo

## 分类

| 分类 | 说明 |
|------|------|
| 编码 Agent | 自主完成编码任务的 AI 工具 |
| 工作流/自动化 | AI 驱动的流程编排和自动化 |
| 本地部署 | 可完全本地运行的 AI 工具 |
| MCP 生态 | Model Context Protocol 相关 |
| 应用构建 | AI 生成全栈应用 |
| Agent 框架 | 构建 AI Agent 的开发框架 |
