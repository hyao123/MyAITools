# MyAITools

AI 工具集合网站 - 个人常用 AI 工具，在线体验，无需安装。

## 功能列表

| 工具 | 描述 |
|------|------|
| 文本摘要 | 输入长文本，自动提取关键内容生成摘要 |
| 智能翻译 | 支持中英文互译（基础词典演示） |
| 情感分析 | 分析文本情感倾向，判断正面/负面/中性 |
| 代码生成 | 描述需求，自动生成对应代码片段 |
| JSON格式化 | 美化、压缩、验证JSON数据 |
| 密码生成器 | 生成安全的随机密码，可自定义规则 |
| Markdown预览 | 实时预览Markdown文本渲染效果 |
| 颜色工具 | 颜色选择、HEX/RGB/HSL转换 |
| 字数统计 | 统计字符数、词数、行数、阅读时间 |

## 使用方式

纯前端静态页面，直接用浏览器打开 `index.html` 即可使用，无需后端服务。

## 技术栈

- HTML5
- CSS3 (渐变背景、毛玻璃效果、响应式设计)
- Vanilla JavaScript (无框架依赖)

## 部署

可直接部署到 GitHub Pages、Vercel、Netlify 等静态托管服务。
